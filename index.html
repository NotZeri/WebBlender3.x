WebBlender 3.x

A shitty but accurate recreation of the Blender 3.x interface with core 3D modeling features.

  • Shift + A Add objects, cameras, or lights
  • Alt + Click Cycles through overlapping parts and their parent groups
  • Right-Click > Separate Splits a multi-material object into separate parts
  • Pose Mode Select a rigged mesh to pose its bones (green dots)
  • I Insert Keyframe for selected object/bone at current frame
  • Spacebar Play/Pause Animation
  • Timeline Click & Drag keyframes to move them. Press X to delete selected.
  • Shift + Click Select multiple objects at once
  • Ctrl + Z / X Undo / Redo
  • Ctrl + G Group selected objects
  • G / R / S Move / Rotate / Scale tool
  • Tab Toggle Edit Mode (vertex editing)
  • X / Delete Delete selected object(s) or keyframe(s)
  • Ctrl + C / V Copy / Paste selected object(s)
  • Z Toggle wireframe / solid
  • F12 Render Image (requires Camera)
  • Numpad 1/3/7 Front / Right / Top view
  • Home Frame all
  • Right-click Context menu (Outliner & 3D View)
  • Drag & Drop Import .obj, .gltf, .glb, or .fbx files
  • Paint Tool Draw textures directly on 3D models
  • Middle-drag Orbit   Shift+Middle Pan   Wheel Zoom
