Blender 3.x — Web Edition

A faithful recreation of the Blender 3.x interface with core 3D modeling features.

  • Shift + A Add objects
  • Shift + Click Select multiple objects at once
  • Ctrl + G Group selected objects
  • G / R / S Move / Rotate / Scale tool
  • Tab Toggle Edit Mode (vertex editing)
  • X / Delete Delete selected object(s)
  • Ctrl + C / V Copy / Paste selected object
  • A Select all (cycles objects in demo)
  • Z Toggle wireframe / solid
  • F12 Render Image (requires Camera)
  • Numpad 1/3/7 Front / Right / Top view
  • Home Frame all
  • Right-click Context menu (Outliner & 3D View)
  • Drag & Drop Import .obj or .gltf files directly into the viewport
  • Paint Tool Draw textures directly on 3D models
  • Middle-drag Orbit   Shift+Middle Pan   Wheel Zoom
